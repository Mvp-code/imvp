# Interface Patterns (Cursor)

## Layouts
- Landing page: clear hero, trust cues, early CTA, layered detail blocks.
- App dashboard: top summary, primary workspace, contextual side panel.
- Settings area: domain-based sections, internal search, explicit save behavior.

## UX flows
- Onboarding: goal -> minimum input -> visible value in fewer than five steps.
- Creation flow: useful default template + progressive customization.
- Review/confirmation: concise summary + localized edit paths.

## Heuristics
- Reduce steps when outcomes are reversible.
- Increase confirmation for destructive or high-impact actions.
- Empty states should always include a recommended next action.
