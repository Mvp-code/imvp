# Cursor Design Principles

## Core philosophy
- Reduce cognitive load and help users make confident decisions quickly.
- Prioritize readability, hierarchy, and predictable interaction behavior.
- Balance brand expression with practical product usability.

## Mental models
- human-centered interactions
- trust-building signals
- clear feedback loops

## Operating rules
- One screen should communicate one primary objective.
- Every critical action must include state, feedback, and recovery paths.
- Prefer familiar patterns before introducing novelty.
