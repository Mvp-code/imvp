2 · The four row actions

ActionWhat happens (all on this page — no navigation except the two legacy forms)
ScorecardOpens a drawer with the exact DA Scorecard from the MVPx Dashboard — same cards, same live data (score ring + standing, Delivery Quality with DCR/RTS, Safety & Compliance, Customer Feedback, Incidents, My Week Flex App with breaks), with the same week dropdown and Current / 6-Wk Trailing switch. It reuses the dashboard's scorecard service directly, so the two can never disagree. No rebuild — one drawer, one existing data call.
Active toggleFlips STATUS Active ↔ Inactive instantly via ajax (green = active, gray = inactive), with a toast. The flip is written to the employee's history ("Marked inactive by vijay, 07/15") so there's a trail. Inactive DAs drop out of wave-sheet matching and check-in suggestors automatically.
EditRight-side drawer (identical pattern to Vehicles). Mobile is editable — when a DA changes numbers you fix it here in 5 seconds; the old number is logged to history ("Mobile changed 908-251-0116 → 908-555-2200"). Also editable: language, SMS pref, ID expiry, role/position, station, TID (read-only display), availability days.
IncidentsDrawer listing every incident for this DA from the Incident page's data (type, date, description, posted state) — newest first, filterable by type — plus a ＋ New Incident quick-add right in the drawer using the same fields as the Incident page (type dropdown from incidenttype, date, vehicle, description). Saved incidents land in the normal incidents table, so the Incident page, dashboard activity, and coaching all see them instantly.
HistoryDrawer showing the full record trail (section 4), top to bottom: termination (if terminated) → incidents (all types, full descriptions) → OSHA incidents with details → schedule (availability days + recent weeks worked) → record changes (status flips, phone changes) → write-ups summary.
OSHAOpens an Add OSHA Incident drawer right here (section 4.6): incident date, type, location, and a full-size description box — saves straight into the OSHA records (employeeincident), shows in the History drawer and the dashboard profile immediately. "Open full OSHA page" link stays for anything unusual.
TerminateOpens an Add Termination drawer (section 4.7): termination date, type, reason, comments — saves the termination record, flips the DA to Inactive, and turns the row into the red TERMINATED chip. Everything the History drawer later shows is captured here. Full termination page link for edge cases.
