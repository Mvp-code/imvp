The Dispatch
Ledger

MVPx is a tool people open at 5 a.m., every day, under time pressure. The redesign treats it like what it is: an operations ledger. Warm paper, hard black ink, monospaced data, hairline rules — and color is spent on exactly one thing: the status of a record. Everything else stays out of the way.

TYPE — Barlow Semi Cond. / Barlow / IBM Plex Mono
CHROME — paper & ink, zero decoration
COLOR — status dots, errors, sidebar only
DENSITY — high; built for 1,000-row days

Two clicks, max

Every daily task — log an incident, confirm a DA, post a day — reachable in two clicks from anywhere. The flat Quick Access rail stays; expand-then-click dies.

Ink on paper

Warm paper ground, near-black ink, white cards. No gradients, no blue chrome. Data is set in a monospaced face so dates, counts and vehicle codes align like a printed manifest.

Color = status

If something is amber, it needs posting. Blue, it’s posted. Green, done. Red, wrong. Color never decorates — so when you see it, it means something.

The Shell & List Pages

shown: Daily Incidents — the busiest page

One dark rail, one paper canvas. The rail is the only colored chrome in the app and holds the flat Quick Access list — every daily page is one click, always visible, with the active page flipped to paper. List pages share one anatomy: title → counters → toolbar → table → footer. Learn it once, use it on every page.

The Record View

one pattern for browse · edit · create

Rows open into a single record sheet. Labels are monospaced tags, values are set large in ink; in edit mode the same grid swaps values for fields, so nothing jumps around. Form controls are strictly black / white / gray — the only red you will ever see is a validation error.

Motion & Rollout

quiet motion · page-by-page delivery
Arrive once

On page load the header, toolbar and table rise in with a short stagger. After that, the page holds still — no idle animation, ever.

120–500ms · ease-out · translateY(14px)
Answer every touch

Rows tint on hover and reveal their arrow; buttons depress 1px on press; focus rings are ink, not blue. Feedback in under 150ms.

120–150ms · background & transform only
Respect the setting

Honors the existing “reduce motion” preference already in MVPx settings — all entrance animation collapses to none.

PhasePagesWhy this order
P1 Shell (sidebar + topbar), Daily Incidents, Daily Inspections The shell carries the whole aesthetic; incidents & inspections are the highest-traffic pages.
P2 DA Confirmations, DA Checkins, DA Checkouts The morning-rush trio — shared list anatomy makes these fast to convert.
P3 OSHA Incidents, Terminations, Employee Forms, Uploads, Daily Uploads Lower frequency; record-sheet pattern covers their forms.
P4 Admin group, Reports, Scorecard, Fleet KPIs Back-office last. Skipped entirely: EmployeeCoachingFollowup, OnBoarding, AdminGasCard, EmployeeDashboard (not in use).
